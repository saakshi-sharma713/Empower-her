-- Why should orders not be stored inside the users table?

Orders should not be stored inside the users table because a single user can place multiple orders. If orders are stored in the users table, we would need to 
create multiple rows for the same user_id, which would lead to 
data repetition. This repetition increases the table size, makes 
the database complex to manage, and causes data redundancy. 
Therefore, orders should be stored in a separate table and 
linked to users using a foreign key.
